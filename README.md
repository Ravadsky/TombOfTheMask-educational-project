# Tomb of the Mask — для XYZ

## Описание

Tomb of the Mask - двумерный платформер с элементами головоломки, в котором игроку придётся управлять персонажем и врезаться во всевозможные стенки, чтобы пройти лабиринты. Текущая версия игры имеет 3 уровня, которые открываются по мере прохождения предыдущего - на уровнях игрока ожидают блоки с шипами и стреляющие по таймеру блоки.

## Управление

В меню:
ЛКМ - нажатие кнопки
Escape - возвращение в главное меню

На уровне:
W - свайп вверх
A - свайп влево
S - свайп вниз
D - свайп вправо

В редакторе:
Движение аналогично движению на уровне
ЛКМ - установить выбранный объект
Колесико мыши - повернуть выбранный объект
ПКМ - удалить выбранный объект
