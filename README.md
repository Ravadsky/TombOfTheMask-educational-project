Учебный проект №1 для платформы XYZ по курсу "с++ для разработки игр"


Игра представляет из себя прототип игры "Tomb of the Mask" - платформу-головоломку, где с помощью свайпов персонаж врезается в стены, а игрок должен с помощью свайпов увернуться от всех опасностей, собрать все награды на уровне и дойти до выхода.
